Detailed Description

Implementeaza interfata IGameStrategy pentru modul de joc Daily Challenge. Aceasta strategie utilizeaza o tabla redusa (5x5) pentru a permite rezolvarea rapida a mai multor puzzle-uri intr-un timp limitat.
